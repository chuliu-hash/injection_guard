#     可用内核只到 torch 2.5 → 故 transformers 必须留在 4.x。
#
# torch 需为 CUDA 12.4 构建（PyPI 的 torch==2.5.1 即 cu124）。若改用 PyTorch 源：
#   pip install --index-url https://download.pytorch.org/whl/cu124 "torch==2.5.1+cu124"
